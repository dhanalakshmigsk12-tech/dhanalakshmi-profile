# Dhanalakshmi — Profile Site

A standalone portfolio site built from a fresh set of files. The supplied portfolio folder was left unchanged; its artwork was copied into `images/` for this project.

## Open it

Open `index.html` in a modern browser. The page uses plain HTML, CSS, and JavaScript and does not need a build step.

## Files

- `index.html` — page content and portfolio sections
- `style.css` — layout, responsive styles, and motion effects
- `script.js` — mobile navigation, scroll reveals, project filters, carousel, and feedback form
- `images/` — copied artwork used by this profile

The profile uses the supplied name, education, location, contact details, and project artwork. Visitor feedback is saved to the existing `portfolio_feedback` table in the Supabase project already configured by the supplied site. The client uses the existing publishable key; access remains governed by that project's database policies.
